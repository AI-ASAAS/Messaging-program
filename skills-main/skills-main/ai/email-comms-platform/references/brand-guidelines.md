# Brand Identity & Typography Guidelines

This reference defines the visual principles and token specifications used across the platform and generated email templates.

## Brand Palette Tokens

| Token | Hex | Role | Usage in Email |
| --- | --- | --- | --- |
| **Ink** | `#221f1f` | Dominant Dark | Email top header bar, body titles, headings, and signature name |
| **Gold** | `#ba9555` | Brand Primary | Header border accents, CTA primary button fill, bullet markers, highlights |
| **Sand** | `#d3c6b4` | Neutral Accent | Card border dividers, subheadings, subtle badge borders |
| **Clay** | `#c3ad8d` | Secondary Accent | Hover states, secondary button outlines, metadata labels |
| **Cream** | `#ede7da` | Background Family | Email outer backdrop canvas in web previews |
| **Paper** | `#fcf9f5` | Surface Clean | Main email outer background, table row stripes |

## Typography: Thmanyah Typeface

The platform embeds authentic WOFF2 cuts of the **Thmanyah** typeface:

1. **Thmanyah Sans (`--font-sans`)**:
   - Used for the user interface, buttons, inputs, email metadata, and **all numbers**.
   - Weights: 400 (Regular), 500 (Medium), 700 (Bold), 900 (Black).
2. **Thmanyah Serif Display (`--font-display`)**:
   - Used for main headlines (`h1` - `h3`), email document titles, and signatory names.
   - Weight: 700 (Bold).
3. **Thmanyah Serif Text (`--font-text`)**:
   - Used for descriptive paragraphs, executive summaries, and formal editorial sections.
